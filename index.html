Le parcours
1. Remplis les groupes
Dans Matchs, commence par tous les scores de phase de groupes.
2. Construis ton Tournoi
L'app calcule tes qualifies. Tu remplis les 32es, puis les 8es, puis chaque tour dans l'ordre.
3. Suis les vrais matchs
Dans Matchs, les phases finales reelles se debloquent seulement quand les vraies equipes sont connues.
Matchs = calendrier reel. Tournoi = ton scenario complet calcule par tes scores.
Comment ça marche
Score exact (ex: tu dis 2-1, c'est 2-1) +3 pts
Bon résultat (ex: tu dis 2-1, c'est 3-0) +1 pt
Mauvais pronostic 0 pt
En phase finale : 5 pts pour le score exact, 2 pts pour le bon résultat.
